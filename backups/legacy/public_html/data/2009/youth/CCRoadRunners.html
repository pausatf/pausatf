Event Guidelines

  • Sub-Bantams, Bantams, and Midgets are allowed 3 events
  • Youth and Open are allowed 4 events
  • All weather track, please use 1/4 inch spikes
  • Report to the Clerk of Course for running events and official at field event location on the first call
  • We will not pre-seed heats
  • All running events will begin with the youngest age division; girls first followed by boys
  • Running events may be combined depending on the number of athletes
  • Each athlete will have up to four attempts in each field event
  • Athletes must supply their own equipment for all throwing events
  • Late arrivals to field events must start at the current round without warm-up
  • No coaches or parents are allowed on the track or field areas.
